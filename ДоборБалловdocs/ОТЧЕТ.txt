ОТЧЕТ
1) Почему один метод быстрее другого?
	Математический метод будет быстрее работать, потому что он выполняет фиксированное число операций для любого числа N(Время 	выполнение всегда одинаково и для больших и для маленьких чисел, но если число достаточно маленькое, то наивный метод будет 	быстрее).Проверка на полный квадарат происходит через бинарный поиск, а он работает быстро. Наивный же метод в свою очередь
	последовательно получает числа фибоначи. Он на каждой итерации выполняет сложение предыдущих чисел=> тратит больше времени

2)Какая теоретическая сложность у каждого метода?
	-Наивный метод: O(logN) так как числа растут умножением
	-Математический метод: тоже  O(logN), так как используем Бинанарный поиск 
3) Соответствуют ли экспериментальные данные теории?
	Да, в наивном методе видно по графику, время растет с увеличение числа N. Он медленный, но есть => O(logN).
	В Математическом методе время приблизительно одинаковое для всех чисел => его график будет прямой
